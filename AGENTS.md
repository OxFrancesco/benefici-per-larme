## Reference codebases (codeview)

The `resources/` folder contains read-only clones of reference codebases.
If you need to implement code specific to one of these codebases, read the relevant
folder to gather information, feedback, patterns, and templates before writing code.

- `resources/pi-durable-cloudflare` — Pi Durable on Cloudflare Durable Objects example: sessions, tools, scheduling
- `resources/alchemy-effect` — Alchemy v2 (Effect v4) IaC: Cloudflare Workers, Vite, D1, examples
- `resources/cloudflare-agents` — Official Cloudflare Agents SDK, PiHarness lifecycle and durable code mode examples

## ui-sdk

Before using ui-sdk, follow the ui-sdk skill if it's installed, and read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a new component, also search `node_modules/@ui-sdk/react/docs/core.md` by heading, and read `rendering.md` next to it.
